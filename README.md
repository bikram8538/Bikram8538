## About Me

I'm a **Frontend Developer and WordPress Developer** focused on building modern, responsive and visually polished websites.

I enjoy transforming **Figma designs into production-ready interfaces**, building responsive frontend experiences, and developing manageable WordPress websites using **Elementor and WooCommerce**.

My approach combines:

- Clean and semantic HTML
- Responsive and accessible UI
- Modern CSS and utility-first styling
- SEO-friendly structure
- Performance-conscious development
- Pixel-focused design implementation

Currently, I'm expanding my skills in **React and modern web development** while continuing to build professional WordPress and frontend solutions.
